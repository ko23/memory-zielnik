# Unified tile size

T1 of a 5-feature tile/data-portability sequencing analysis: give every memory-game tile — face-down, face-up, and matched — a consistent fixed footprint (100×100px square) in `GameBoard.tsx`, regardless of a herb card's original image aspect ratio or name length. Standalone from T2 (cauldron tile back) and T3 (multi-row grid), which are planned separately later but depend on this one.

See `plan-brief.md` for the two-page summary and `plan.md` for the full implementation plan.
