# Herb seed cards

A one-time generation script turns the 14 source JPGs in `./herbs-pictures` into a committed seed-data file, plus a `seedDefaultCards()` function that populates an empty deck from it using `F-01`'s existing `createCard` contract.

See `plan-brief.md` for the two-page summary and `plan.md` for the full implementation plan.
